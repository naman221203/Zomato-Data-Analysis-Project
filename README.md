Zomato Data Analysis
📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on Zomato restaurant data using Python. The objective is to understand restaurant types, customer ratings, voting patterns, average spending, online ordering preferences, and the relationship between restaurant types and ordering modes.

The analysis uses Pandas, NumPy, Matplotlib, and Seaborn to clean, analyze, and visualize the data.

🎯 Objectives

The main objectives of this project are:

- Analyze different types of restaurants listed on Zomato.
- Identify which restaurant category receives the most customer votes.
- Analyze the distribution of restaurant ratings.
- Calculate the average spending for two people.
- Compare ratings between online and offline orders.
- Identify which restaurant types receive more online or offline orders.
- Generate meaningful insights through data visualization.

🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization

📊 Dataset

The project uses a Zomato restaurant dataset containing information such as:

- Restaurant name
- Restaurant type
- Customer ratings
- Number of votes
- Online ordering availability
- Approximate cost for two people

  📌 Conclusion

The Zomato dataset provides useful insights into restaurant categories, customer ratings, voting behavior, spending patterns, and ordering preferences.

The analysis shows that Dining restaurants form a major portion of the dataset and receive the highest number of votes. Restaurant ratings are largely concentrated between 3.5 and 4.0, while the calculated average spending for two people is 418.24.

The comparison between online and offline orders also indicates differences in customer ratings and ordering behavior across restaurant categories.

Overall, this project demonstrates how Python-based exploratory data analysis and visualization can be used to identify meaningful patterns in restaurant and customer data.
